# 64KG Android App

安卓本地减重记录 App。数据保存在手机本地，关闭或重新打开 App 不会丢失。

## 功能
- 当前体重与 2026-10-01 倒数日同级展示
- 自动计算距离目标 64 kg 还有多少
- 每日体重记录与趋势图
- 早餐、午餐、晚餐、加餐热量建议
- 每周最多两次液断日，可当天选择或随机安排
- 跑步 / 打球 / 休息记录
- 摄入超过 1500 kcal 或未运动时提醒

## APK

GitHub Actions 会在 main 分支更新后自动构建 APK，并上传为 workflow artifact，同时发布 `latest` Release。
